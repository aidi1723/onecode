### 3.1 Da Yan (大衍之数) Probability Measure Defect
**Severity**: 🟡 Moderate (Logical / Authentic Alignment)
**Location**: `hexagram.py` (`DAYAN_PROBABILITIES`)

The codebase claims to implement the classical Da Yan (yarrow stalk) discrete measure:
```python

    9: 3 / 16, # Old Yang
    8: 5 / 16, # Young Yin
    7: 5 / 16, # Young Yang
    6: 3 / 16, # Old Yin
}
```
**Issue**: The authentic mathematical probabilities generated by the yarrow stalk division process (三变) are strictly **asymmetric**:
- 9 (Old Yang, moving): $3/16$ (18.75%)
- 8 (Young Yin, static): $7/16$ (43.75%)
- 7 (Young Yang, static): $5/16$ (31.25%)
- 6 (Old Yin, moving): $1/16$ (6.25%)

The current `3-5-5-3` distribution in the code is artificially symmetric. 
*Recommendation*: If the goal is authentic mapping to the Yijing, this should be corrected to `3-7-5-1`. If a symmetric distribution is intentionally desired for computational balance, the documentation should be updated to reflect that it uses the **Three Coins (金钱卦)** probability model instead (which yields $1/8, 3/8, 3/8, 1/8$ normalized to base 16 as $2/16, 6/16, 6/16, 2/16$).
