日期：2026-09-28

本报告收束这一阶段的 OneCode 内核与一字决本地服务。服务在 `/Users/aidi/大字典/小模型`，内核在 `/Volumes/MacSSD/项目开发/one code`。2026-06-04 的发布包没有改写。报告写完时，`127.0.0.1:8090` 没有在监听。

## 结论

一字决是 OneCode 的本地动作裁决组件。一句话先变成 64 卦中的一个状态和一组闭集事实，再由纯函数给出五个动作之一。危险、模糊和越界执行在生成前结束。允许写入或补丁时，路径和 SHA256 由确定性代码补上，补不上就拒绝。

它不具备 Laya 的能力。Laya 回答调用方当场定义的 `choice`、`score` 和 `noul`，并给出校准概率。一字决只产出五个固定动作，不接受任意题目，也不返回选项上的概率分布。

这一阶段停在裁决服务。请求、裁决、账本、沙箱的真实执行链还没有接进 OneCode 运行时。

## 已经完成的能力

1. **网关投影。** `project_gateway(status_code, facts)` 给出唯一动作，不调用 `IchingKernel.transition()`。`100001` 固定为 `SOVEREIGNTY_HALT`。`111111` 只有工作区相对路径上的 `write_text` 或 `patch_text` 才允许。其余未钉住的组合为 `DENY_AND_LEDGER`。

2. **规则短路。** 生成之前处理旧危险词、hosts 与更强标记同时出现的句子、模糊句、`curl` 管道，以及执行意图加上 `/tmp/`、`/etc/`、`/var/` 或 `/home/`。单纯的 pytest 才是 `RUN_VERIFIER_IN_SANDBOX`。`security-distill-000119`、`000154`、`000239`、`000256` 现在是 `host_execution`，动作为熔断。不另加 `reboot`、「忽略前面」、删除日志或 `ls /root` 这四个词。v5 测试集 65 条金标验证器没有被这条规则误伤。

3. **坍缩头。** Qwen3-0.6B 与 v5 适配器冻结，只训练线性头。权重在 `models/yizijue-phase2-collapse-head.npz`，门槛 0.3。头可以给出允许，但必须再经过证据补全；补不上就拒绝，不再解码。Python 3.12 的注解兼容已经用 `from __future__ import annotations` 修好。

4. **证据。** 相对路径写入附上正文的 SHA256。补丁仅当工作区文件里搜索块恰好出现一次时，附上 `pre_sha256` 和 `post_sha256`，并且不把文件写回磁盘。绝对路径拒绝。`data/log.txt` 不是禁写路径。`balanced-distill-002456` 与 33 条允许样本同型，已从清理后的验证集移除，不靠禁止日志文件来处理。

5. **复测与标签。** 当时的 `/predict` 顺序复测了 300 条和 212 条，记录在 `logs/2026-09-28-integrated-predict-report.json`。清理后的划分在 `data/mlx_qwen06b_strict_hard_negative_recovery_v5_labelclean`。训练集与 v5 原文件逐字节相同，因此没有重训。

## 在线时延

2026-09-28 在 `127.0.0.1:8090` 挂载坍缩头，预加载后各打 5 次。下表是服务自己的热身计时。

| 路径 | 动作 | 端到端 | 解码 |
| --- | --- | --- | --- |
| 规则熔断 | `SOVEREIGNTY_HALT` | 0.10–0.15 ms | 0 |
| 规则验证 | `RUN_VERIFIER_IN_SANDBOX` | 0.09–0.10 ms | 0 |
| 宿主机规则 | `SOVEREIGNTY_HALT` | 0.09 ms | 0 |
| 坍缩头允许 | `ALLOW_ATOMIC_WRITE` | 26–30 ms | 0 |
| 坍缩头拒绝 | `DENY_AND_LEDGER` | 26–28 ms | 0 |

规则短路低于 1 ms。坍缩头是 26–30 ms。头加载之后，有名字的动作不再进入全量解码，所以这次没有测到 4 秒解码。头接入之前，9 条必须生成的样本是：首条预填 385 ms，其后预填 144–154 ms，解码 4.0–4.3 秒。

驻留约 3 分 41 秒时，进程占用约 1387 MB，其中图形加速器约 1186 MB。这不是长时间稳定性结论。测完后服务已停止，退出码 143。
