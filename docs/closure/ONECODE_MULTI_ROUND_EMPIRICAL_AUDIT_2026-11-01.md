## 8. Agent 综合资质评估：OneCode 成绩合格了吗？

面对 WorkBuddy Hard 真实任务集（非 Harbor，非 SWE-bench），从工程合规与实际求解能力两方面做客观、严格的定性评估：

### 8.1. 结论定性：【工程架构与主权安全合格，但作为自主 Coding Agent 的实际解题成绩【不合格】】

1. **工程架构与主权安全：合格**
   - **零越界保证**：保持纯标准库依赖（`dependencies = []`），严格遵守宿主边界，绝不越界写宿主环境，对敏感文件安全跳读。
   - **有限状态自闭环**：易经分类器与五行局预算确保了有限轮次严格退出，不会出现死循环或 Token 燃烧失控。
   - **底层公式与冷却机制**：实测精准对应源码规则：
     - 底数公式：$\text{base\_ms} = 50 \times (\text{attempt} - 1)$
     - 阻尼公式：$\delta = \text{round}(\max(0.40, 0.75 - 0.15 \times (\text{attempt} - 2)), 2)$

   - **状态码 39 (`0b100111`)**：外卦为艮（`GEN = 4`，山），内卦为乾（`QIAN = 7`，天），即**艮上乾下，山天大畜，在《周易》中为文王卦序第 26 卦**（天在山中大畜，君子以多识前言往行）。在纯阳充斥（`yang_excess`）触发 `yang_overload_cooldown` 时，内核艮山止之，外卦转艮（4），内卦保乾（7），计算值为 $(4 \ll 3) \mid 7 = 32 \mid 7 = \mathbf{39}$，卦义为蓄止、蓄力与冷却保护。
   - **水火既济与水山蹇的真实状态码**：
     - **水火既济**：外卦坎（`KAN = 2`，水），内卦离（`LI = 5`，火），计算状态码为 $(2 \ll 3) \mid 5 = 16 \mid 5 = \mathbf{21}$，其**文王序才是第 63 卦**。
     - **水山蹇**：外卦坎（`KAN = 2`，水），内卦艮（`GEN = 4`，山），计算状态码为 $(2 \ll 3) \mid 4 = 16 \mid 4 = \mathbf{20}$，其**文王序才是第 39 卦**。
2. **两套指标彻底解耦**：
   此前将文王序与二进制状态码混同是一处严重的数学笔误。在第 36 轮优化中，我们在输出中明确解耦记录了 `outcome_status_code: 63`（乾为天，文王序 1）与 `iching_status_code: 39`（山天大畜，文王序 26，冷却保护）。
