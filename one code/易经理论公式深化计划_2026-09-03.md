### 1.2 已实现公式 ✅

#### 阴阳平衡公式
```python
阳爻计数 = sum(1 for line in lines if line == 1)
阴爻计数 = 6 - 阳爻计数
极性指数 = 阳爻计数 / 6

平衡判断:
- pure_yang:     阳爻 == 6        (纯阳)
- yang_excess:   极性 > 2/3       (阳盛)
- yang_majority: 1/2 < 极性 ≤ 2/3 (阳多)
- balanced:      1/3 ≤ 极性 ≤ 1/2 (平衡)
- yin_majority:  0 < 极性 < 1/3   (阴多)
- pure_yin:      阳爻 == 0        (纯阴)
```

#### 五行生克关系
```python
相生环: 木 → 火 → 土 → 金 → 水 → 木
相克环: 木 → 土 → 水 → 火 → 金 → 木

八卦配五行:
坤(000) → 土    震(001) → 木
坎(010) → 水    兑(011) → 金
艮(100) → 土    巽(110) → 木
离(101) → 火    乾(111) → 金
```

#### 和谐度计算
```python
关系分数:
generates(相生):      +2
same(同元素):         +1
generated_by(被生):   +1
neutral(中性):         0
controls(相克):       -1
controlled_by(被克):  -2

卦象和谐度 = 外卦元素 与 内卦元素 的关系分数
```

#### 互卦（核卦）公式
```python
互卦 = 由2、3、4爻组成下卦，3、4、5爻组成上卦
例: 111000 (乾坤)
    234爻: 110 → 巽
```

## 二、可补充的经典易经理论

### 2.1 卦变理论 ⭐⭐⭐ 高价值

#### 错卦（对卦）
**定义**: 所有爻位阴阳互换

```python
错卦公式:
错卦 = NOT(原卦的每一爻)
例: 111000 (乾坤) → 000111 (坤乾)

实现价值:
- 表示对立面、反向状态
- 用于恢复策略的对称性分析
- 检测状态的互补性
```

#### 综卦（覆卦）
**定义**: 卦象上下颠倒

```python
综卦公式:
综卦 = 将6爻顺序完全颠倒
例: 111000 (乾坤) → 000111 (坤乾)

实现价值:
- 表示视角转换
- 用于对称性检验
- 分析双向关系
```

### 2.2 爻位理论 ⭐⭐⭐ 高价值

#### 当位/不当位
**定义**: 阳爻居阳位为当位，阴爻居阴位为当位

```python
爻位奇偶:
初爻(1) = 阳位    二爻(2) = 阴位
三爻(3) = 阳位    四爻(4) = 阴位
五爻(5) = 阳位    上爻(6) = 阴位

当位判断:
is_yang_position = (position % 2 == 0)
is_proper = (is_yang_position == is_yang_line)

实现价值:
- 评估卦象的"正位"程度
- 影响转换决策的权重
```

#### 得中/失中
**定义**: 二爻、五爻为中位，居中为吉

```python
中位判断:
下卦中位 = 二爻(索引1)
上卦中位 = 五爻(索引4)

实现价值:
- 中正位的特殊权重
- 符合"中庸之道"
```

#### 承乘比应
**定义**: 爻与爻之间的关系

```python
应对关系:
初爻(0) 应 四爻(3)
二爻(1) 应 五爻(4)
三爻(2) 应 上爻(5)

关系得分:
- 阴阳相应 → +2 (吉)
- 同性相应 → +0 (平)

实现价值:
- 内外卦的互动关系
- 细粒度的爻位影响
```

### 2.3 五行旺衰理论 ⭐⭐ 中价值

#### 旺相休囚死
**定义**: 五行在不同季节的强弱状态

```python
五行时令旺衰:
           春    夏    长夏   秋    冬
木:        旺    相    死     囚    休
火:        相    旺    休     死    囚
土:        死    休    旺     相    囚
金:        囚    死    相     旺    休
水:        休    囚    死     休    旺

旺 = 当令 (×2.0)
相 = 次旺 (×1.5)
休 = 休养 (×1.0)
囚 = 受制 (×0.5)
死 = 最弱 (×0.2)

实现价值:
- 引入时间维度
- 动态调整元素权重
```

## 三、实施优先级

### 高优先级（建议实施）

#### 任务 1: 错卦公式（1-2天）
```python
@classmethod
def contrary_hexagram(cls, status_code: int) -> int:
    """计算错卦（所有爻阴阳互换）"""
    normalized = status_code & 0b111111
    return (~normalized) & 0b111111
```

#### 任务 2: 综卦公式（1-2天）
```python
@classmethod
def inverse_hexagram(cls, status_code: int) -> int:
    """计算综卦（上下颠倒）"""
    normalized = status_code & 0b111111
    lines = cls.lines(normalized)
    reversed_lines = lines[::-1]
    result = sum(line << i for i, line in enumerate(reversed_lines))
    return result
```

#### 任务 3: 爻位当位理论（2-3天）
```python
@classmethod
def position_propriety(cls, status_code: int) -> dict:
    """爻位当位分析"""
    lines = cls.lines(status_code & 0b111111)
    proper_count = sum(
        1 for i, line in enumerate(lines)
        if (i % 2 == 0) == (line == 1)
    )
    return {
        "proper_count": proper_count,
        "propriety_ratio": proper_count / 6
    }
```

#### 任务 4: 中正位理论（2-3天）
```python
@classmethod
def central_correctness(cls, status_code: int) -> dict:
    """中正位分析（二爻、五爻）"""
    lines = cls.lines(status_code & 0b111111)
    lower_correct = (lines[1] == 0)  # 二爻阴位
    upper_correct = (lines[4] == 1)  # 五爻阳位
    return {
        "lower_central_correct": lower_correct,
        "upper_central_correct": upper_correct,
        "both_correct": lower_correct and upper_correct
    }
```

#### 任务 5: 承乘比应关系（3-4天）
```python
@classmethod
def line_relationships(cls, status_code: int) -> dict:
    """爻位关系分析"""
    lines = cls.lines(status_code & 0b111111)
    
    # 应对关系
    response_scores = []
    for lower, upper in cls.RESPONSE_PAIRS:
        is_complementary = (lines[lower] != lines[upper])
        weight = 1.5 if (lower in [1,4] or upper in [1,4]) else 1.0
        score = (2 if is_complementary else 1) * weight
        response_scores.append(score)
    
    return {
        "total_response_score": sum(response_scores)
    }
```
