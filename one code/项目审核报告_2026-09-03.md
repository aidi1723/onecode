## 一、项目概况

### 1.1 项目定位

OneCode 是一个本地优先的智能体内核原型，专注于：
- 作用域文件写入
- 仅追加式运行证据
- 有状态恢复机制
- 基于易经的确定性状态画像

### 1.2 核心特征

- **零第三方运行时依赖**（核心内核）
- **GPL-3.0-only 开源许可**
- **易经六十四卦状态机**驱动决策
- **本地优先架构**，安全边界清晰
- **完整的证据链追踪**（append-only trace）

### 4.2 设计原则遵循度

✅ **权威链完整性**: 
```
yin/yang 位 → 三卦 → 五行生克 → 阴阳压力/动态平衡 → 转换 → 调度
```

✅ **规则闭包原则**: 
- 外部事实作为证据，不作为规则
- 所有修复必须闭合在 6-bit 状态码表面
- 禁止引入置信度、优先级、重试分数等并行控制变量

✅ **证据完整性**:
- 仅追加式 JSONL 追踪
- SHA256 证据链
- WAL（Write-Ahead Log）恢复
