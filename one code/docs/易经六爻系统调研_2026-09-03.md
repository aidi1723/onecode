## 一、六爻系统核心概念

### 1.1 纳甲法（装天干地支）

**定义**: 为64卦的每一爻分配天干地支

**口诀**:
```
乾内甲子外壬午，坎内戊寅外戊申；
震内庚子外庚午，艮内丙辰外丙戍；
坤内乙未外癸丑，巽内辛丑外辛未；
离内己卯外己酉，兑内丁巳外丁亥；
```

**规律**:
- 阳卦（乾坎震艮）: 顺时针纳甲
- 阴卦（坤巽离兑）: 逆时针纳甲
- 天干固定，地支按子丑寅卯...循环
- **实际应用**: 天干作用较小，通常只纳地支 + 五行

**公式化表示**:
```
八卦 → 地支序列（6个）
乾: 子寅辰午申戌
坎: 寅辰午申戌子
震: 子寅辰午申戌
艮: 辰午申戌子寅
坤: 未巳卯丑亥酉
巽: 丑亥酉未巳卯
离: 卯丑亥酉未巳
兑: 巳卯丑亥酉未
```

### 1.2 装六亲法

**定义**: 以卦宫五行为"我"，建立六亲关系网

**六亲规则**:
```
生我者 → 父母
我生者 → 子孙
比肩者 → 兄弟
我克者 → 妻财
克我者 → 官鬼
```

**公式**:
```python
卦宫五行 = 卦归属宫的五行属性
for 爻 in 六爻:
    if 爻.五行 == 卦宫五行:
        爻.六亲 = "兄弟"
    elif 爻.五行 生 卦宫五行:
        爻.六亲 = "父母"
    elif 卦宫五行 生 爻.五行:
        爻.六亲 = "子孙"
    elif 卦宫五行 克 爻.五行:
        爻.六亲 = "妻财"
    elif 爻.五行 克 卦宫五行:
        爻.六亲 = "官鬼"
```

**关键点**: 
- 变卦的六亲必须按**本卦**卦宫五行来装
- 避免本卦和变卦的六亲出现不一致

### 1.3 安世应法

**定义**: 确定世爻（自己）和应爻（对方/事）的位置

**算法**:
```
1. 八纯卦（上下卦相同）→ 世爻在六爻
2. 非八纯卦:
   - 从初爻开始，逐爻阴阳互变
   - 直到内外卦变成相同 → 该爻为世爻
   - 该相同卦即为卦宫归属
3. 如果变到五爻仍不同 → 转向四爻往下变
4. 如果变到初爻才相同 → 归魂卦，世爻在三爻
5. 应爻 = 世爻 + 3（相隔两爻）
```

**例**: 山水蒙（艮坎）
```
从初爻开始阴阳互变:
艮(100) 坎(010) → 变初爻 → 艮(100) 离(101)
                → 变二爻 → 艮(100) 坤(000)
                → 变三爻 → 艮(100) 震(001)
                → 变四爻 → 离(101) 离(101) ✓
世爻在四爻，卦归离宫（火）
应爻在初爻（四爻+3模6=1）
```

## 二、动态决策系统

### 2.1 用神、元神、忌神、仇神

**用神**: 主事爻，根据预测事项选择对应六亲
```
测财运 → 妻财
测事业 → 官鬼
测健康 → 子孙
测父母 → 父母
测兄弟 → 兄弟
```

**元神**: 生用神的爻（有利因素）
**忌神**: 克用神的爻（不利因素）
**仇神**: 克元神的爻（间接伤害用神）

**公式**:
```
用神 = 六亲[预测事项]
元神 = {爻 | 爻.五行 生 用神.五行}
忌神 = {爻 | 爻.五行 克 用神.五行}
仇神 = {爻 | 爻.五行 克 元神.五行}
```

**例**: 测财得离为火卦（妻财酉金为用神）
```
用神: 酉金（妻财）
元神: 未土、丑土（土生金）
忌神: 巳火（火克金）
仇神: 卯木（木克土，间接伤金）
```

### 2.2 月建（旺衰权重系统）

**定义**: 起卦时月份的地支，决定爻的旺衰程度

**10层旺衰等级**:
```
旺相级别:
1. 临月建    - 爻与月建地支相同（最旺）
2. 月建生合  - 月建相生且相合
3. 月扶      - 爻五行与月建五行相同
4. 月生      - 爻受月建相生

有气级别:
5. 月建平合  - 月建相合但不相生
6. 月气      - 每季度最后一个月的余气

衰败级别:
7. 休囚      - 月建对爻无作用
8. 月建克合  - 月建克爻但相合（网开一面）
9. 月克      - 爻被月建相克
10. 月破     - 爻与月建相冲（最衰）
```

**公式化**:
```python
def 旺衰等级(爻, 月建):
    if 爻.地支 == 月建.地支:
        return 1  # 临月建
    elif 月建.五行 生 爻.五行 and 月建.地支 合 爻.地支:
        return 2  # 月建生合
    elif 爻.五行 == 月建.五行:
        return 3  # 月扶
    elif 月建.五行 生 爻.五行:
        return 4  # 月生
    elif 月建.地支 合 爻.地支:
        return 5  # 月建平合
    elif 爻.地支 in 月建季度余气表:
        return 6  # 月气
    elif 爻.五行 生 月建.五行 or 爻.五行 克 月建.五行:
        return 7  # 休囚
    elif 月建.五行 克 爻.五行 and 月建.地支 合 爻.地支:
        return 8  # 月建克合
    elif 月建.五行 克 爻.五行:
        return 9  # 月克
    elif 爻.地支 冲 月建.地支:
        return 10  # 月破
```

**实例**: 寅月（正月）各爻旺衰
```
寅木: 临月建（1级）
卯木: 月扶（3级）
巳火/午火: 月生（4级）
亥水: 月建平合（5级）
子水/酉金: 休囚（7级）
辰戌丑未土: 月克（9级）
申金: 月破（10级）
```

### 2.3 三合局（组合增强）

**定义**: 三个地支组成整体，发挥巨大作用

**四组三合局**:
```
申子辰 → 合水局
寅午戌 → 合火局
亥卯未 → 合木局
巳酉丑 → 合金局
```

**成局条件**:
```
1. 三个地支全部发动
2. 一爻动、三爻动 + 变爻组成三合
3. 四爻动、六爻动 + 变爻组成三合
4. 包含中间地支的两动爻 + 日辰/月建补足
5. 中间地支发动 + 日月补足另两支
```

**作用**:
- 三合局以中间地支五行为属性
- 一旦成局，按合局方式论吉凶，不再按原动爻论
- 生用神/元神为吉，克用神/元神为凶
- 力量强大，难以解救

**公式**:
```python
def 检查三合局(卦):
    三合模式 = [
        ("申", "子", "辰", "水"),
        ("寅", "午", "戌", "火"),
        ("亥", "卯", "未", "木"),
        ("巳", "酉", "丑", "金")
    ]
    for 首, 中, 尾, 五行 in 三合模式:
        if 满足成局条件(首, 中, 尾):
            return (True, 五行, (首, 中, 尾))
    return (False, None, None)
```

## 三、与 OneCode 现有系统的对比

### 3.1 相同之处

| 概念 | OneCode | 六爻系统 |
|------|---------|----------|
| 状态表示 | 6-bit 状态码 | 六爻卦象 |
| 五行理论 | 八卦配五行 | 地支配五行 |
| 关系网络 | 五行生克 | 五行生克 + 六亲关系 |
| 动态决策 | transition() | 用神/元神/忌神 |
| 时间权重 | 无（可选 Phase 3） | 月建旺衰系统 |

### 3.2 差异之处

| 维度 | OneCode | 六爻系统 |
|------|---------|----------|
| **复杂度** | 规则闭合在 6-bit 表面 | 引入外部变量（月建、日辰、时辰） |
| **确定性** | 纯函数，状态→转换 | 需要起卦时间参数 |
| **权重系统** | 阴阳平衡 + 五行关系 | 10级旺衰 + 三合局 |
| **应用场景** | Agent 调度决策 | 占卜预测 |
| **数学稳定** | Lyapunov 非递增 | 无数学证明 |
| **六亲关系** | 无 | 核心决策依据 |
| **纳甲地支** | 无 | 核心装卦步骤 |

**1. 纳甲地支映射**
```python
# 为每个状态码的六爻分配地支
def hexagram_earthly_branches(status_code: int) -> list[str]:
    """
    返回六爻对应的地支序列
    可用于：季节分析、方位分析、时间相关决策
    """
    inner = status_code & 0b111
    outer = (status_code >> 3) & 0b111
    
    # 八卦纳甲表
    TRIGRAM_BRANCHES = {
        0b111: ["子", "寅", "辰", "午", "申", "戌"],  # 乾
        0b010: ["寅", "辰", "午", "申", "戌", "子"],  # 坎
        0b001: ["子", "寅", "辰", "午", "申", "戌"],  # 震
        0b100: ["辰", "午", "申", "戌", "子", "寅"],  # 艮
        0b000: ["未", "巳", "卯", "丑", "亥", "酉"],  # 坤
        0b110: ["丑", "亥", "酉", "未", "巳", "卯"],  # 巽
        0b101: ["卯", "丑", "亥", "酉", "未", "巳"],  # 离
        0b011: ["巳", "卯", "丑", "亥", "酉", "未"],  # 兑
    }
    
    inner_branches = TRIGRAM_BRANCHES[inner][:3]
    outer_branches = TRIGRAM_BRANCHES[outer][3:]
    return inner_branches + outer_branches
```

def seasonal_strength(status_code: int, month: int) -> dict:

## 四、扩展建议

### 4.1 高优先级（可立即实现）

#### 建议 A: 纳甲地支映射（参考维度）
- **用途**: 日志输出、可视化、调试
- **实现难度**: 低（查表法）
- **影响范围**: 零侵入，不改变现有决策
- **价值**: 完善易经理论体系的完整性

#### 建议 B: 卦宫归属算法
- **用途**: 确定状态的"根"属性
- **实现难度**: 中（需要实现安世应算法）
- **影响范围**: 新增维度，现有决策不变
- **价值**: 为后续六亲关系和旺衰系统打基础

### 4.2 中优先级（可选 Phase 3）

#### 建议 C: 月建旺衰权重系统
- **用途**: 动态调整转换决策权重
- **实现难度**: 中高
- **影响范围**: **需要外部时间参数**
- **价值**: 引入时间敏感的决策能力
- **前置条件**: 
  - 明确时间参数来源（系统时钟？用户输入？）
  - 设计权重与现有规则的融合策略
  - 保证 Lyapunov 稳定性不被破坏

#### 建议 D: 三合局组合增强
- **用途**: 识别特殊状态组合的强化效应
- **实现难度**: 中
- **影响范围**: 新增决策分支
- **价值**: 更精细的状态关系建模

### 4.3 低优先级（研究性质）

#### 建议 E: 六亲关系网
- **用途**: 参考维度，可视化，语义增强
- **实现难度**: 中低
- **影响范围**: 零侵入
- **价值**: 提供另一种视角理解状态关系

## 六、风险评估

### 6.1 复杂度风险 ⚠️
- **问题**: 六爻系统引入大量外部变量（月建、日辰、时辰、三合局）
- **影响**: 可能破坏 OneCode 的"规则闭包"原则
- **缓解**: 
  - 阶段 1 仅实现参考维度，不改变决策
  - 阶段 2 将时间参数设计为可选上下文
  - 保持 `transition(status_code)` 的核心接口不变

### 6.2 确定性风险 ⚠️
- **问题**: 月建旺衰系统依赖外部时间，可能失去确定性
- **影响**: 同一状态在不同时间可能有不同转换
- **缓解**:
  - 设计两套接口：
    - `transition(status_code)` - 原有确定性接口
    - `transition_with_context(status_code, context)` - 时间敏感接口
  - 文档明确说明时间参数的可选性

### 6.3 数学证明风险 ⚠️
- **问题**: 引入权重调制可能破坏 Lyapunov 非递增性质
- **影响**: 系统稳定性证明失效
- **缓解**:
  - 每次修改后重新运行 `math-audit`
  - 设计权重调制时确保不引入能量递增
  - 必要时将时间系统作为独立层，不改变核心转换逻辑

### 6.4 过度工程风险 ⚠️
- **问题**: 六爻系统过于复杂，可能不适合 Agent 调度场景
- **影响**: 投入大量时间实现了用不上的功能
- **缓解**:
  - 严格遵循分阶段实施
  - 阶段 1 完成后评估实际应用价值
  - 阶段 2 标记为可选，根据实际需求决定是否实施

## 七、总结

### 核心发现
1. **六爻系统是易经预测的工程化实现**，包含完整的状态表示、关系网络、动态权重系统
2. **OneCode 已实现六爻系统的核心**（六爻、五行、阴阳平衡、爻位关系）
3. **六爻系统的独特价值**在于：
   - 纳甲地支映射（时间/方位维度）
   - 月建旺衰权重（时间敏感决策）
   - 三合局组合增强（状态组合识别）
   - 六亲关系网（语义层面的关系建模）

### 扩展建议
- **立即可做**: 纳甲地支映射 + 卦宫归属算法（纯参考维度）
- **谨慎考虑**: 月建旺衰系统（需要时间参数，可能破坏确定性）
- **研究性质**: 六亲关系网（提供新视角，但应用场景不明确）

### 设计原则
