## 一、功能概述

本次扩展为 OneCode 易经内核新增了三个参考维度方法：

1. **纳甲地支映射** (`hexagram_earthly_branches`)
   - 为64卦的每一爻分配对应的地支（子丑寅卯辰巳午未申酉戌亥）
   - 用途: 时间分析、方位分析、季节权重计算的基础数据

2. **卦宫归属算法** (`palace_attribution`)
   - 实现安世应算法，确定每个卦的宫归属、世爻、应爻位置
   - 用途: 确定状态的"根"属性，建立八宫卦序体系

3. **六亲关系网** (`six_relatives_profile`)
   - 基于卦宫五行，为每一爻装配六亲关系（兄弟/父母/子孙/妻财/官鬼）
   - 用途: 语义层面的关系建模，类似"用神/元神/忌神/仇神"体系

## 三、六亲关系语义说明

### 3.1 五种六亲关系

| 六亲 | 英文 | 与卦宫关系 | 传统语义 |
|------|------|------------|----------|
| 兄弟 | brother | 同五行 | 竞争者、帮手、同侪 |
| 父母 | parent | 生卦宫 | 有利因素、保护、根源 |
| 子孙 | offspring | 卦宫生之 | 受保护者、制约官鬼 |
| 妻财 | wealth | 卦宫克之 | 掌控对象、资源、目标 |
| 官鬼 | officer | 克卦宫 | 制约因素、阻力、权威 |

### 3.2 在 OneCode 中的应用场景

## 七、API 使用示例

### 7.1 基础用法

```python
from onecode.kernel.hexagram import IchingKernel

# 任意状态码（0-63）
status_code = 20

# 1. 获取纳甲地支
branches = IchingKernel.hexagram_earthly_branches(status_code)
print(f"地支: {' '.join(branches)}")
# 输出: "辰 午 申 申 戌 子"

# 2. 获取卦宫归属
palace = IchingKernel.palace_attribution(status_code)
print(f"卦宫: {palace['palace_name']}宫")
print(f"世爻: 第{palace['world_line']+1}爻")
print(f"应爻: 第{palace['response_line']+1}爻")

# 3. 获取六亲关系
relatives = IchingKernel.six_relatives_profile(status_code)
print(f"卦宫五行: {relatives['palace_element']}")
for line in relatives['lines']:
    print(f"  第{line['line_index']+1}爻: {line['relative']}")
```

### 7.2 日志增强用法

```python
def enhanced_transition_log(status_code: int):
    """为转换日志增加六爻维度信息"""
    transition = IchingKernel.transition(status_code)
    palace = IchingKernel.palace_attribution(status_code)
    relatives = IchingKernel.six_relatives_profile(status_code)
    
    world_line = palace["world_line"]
    world_relative = relatives["lines"][world_line]["relative"]
    
    return {
        "status": status_code,
        "action": transition.action,
        "reason": transition.reason,
        "palace": palace["palace_name"],
        "world_line": world_line + 1,
        "world_relative": world_relative
    }

# 使用示例
log = enhanced_transition_log(20)
print(f"Status {log['status']}: {log['action']} "
      f"(palace={log['palace']}, world={log['world_relative']})")
# 输出: "Status 20: continue (palace=kun, world=offspring)"
```

### 7.3 批量分析用法

```python
def analyze_all_hexagrams():
    """分析所有64卦的卦宫分布"""
    palace_distribution = {}
    
    for status in range(64):
        palace = IchingKernel.palace_attribution(status)
        palace_name = palace["palace_name"]
        palace_distribution[palace_name] = \
            palace_distribution.get(palace_name, 0) + 1
    
    for palace_name, count in sorted(palace_distribution.items()):
        print(f"{palace_name}宫: {count}个卦")

# 预期输出: 每个宫各8个卦
analyze_all_hexagrams()
```

## 八、注意事项

### 8.1 用途限制

**仅用于参考维度**:
- ✅ 可视化标注
- ✅ 日志输出
- ✅ 调试追踪
- ✅ 语义解释

**不用于决策逻辑**:
- ❌ 不改变 `transition()` 的决策
- ❌ 不引入新的转换规则
- ❌ 不影响 Lyapunov 稳定性
- ❌ 不破坏状态机闭合性

### 8.2 确定性保证

所有新增方法都是**纯函数**:
- 输入: 仅 `status_code` (0-63)
- 输出: 确定性的数据结构
- 无外部依赖: 不需要时间、随机数、配置
- 幂等性: 相同输入永远返回相同输出

### 8.3 性能影响

所有方法都是 **O(1)** 复杂度:
- `hexagram_earthly_branches()`: 数组查找
- `palace_attribution()`: 穷举常量级（最多64次比较）
- `six_relatives_profile()`: 6个爻遍历 + 常量查表

对系统性能**无显著影响**。
