```python
# src/onecode/kernel/hexagram.py
CENTRAL_CORRECT_POSITIONS = (1, 4)  # 二爻、五爻（0-indexed）

@classmethod
def response_strength(cls, status_code: int) -> dict:
    """计算响应对的强度"""
    lines = cls.lines(status_code)
    strengths = {}
    
    for lower, upper in cls.RESPONSE_PAIRS:
        # 阴阳相应得分
        if lines[lower] != lines[upper]:  # 一阴一阳
            base_score = 2
        else:
            base_score = 1
        
        # 中正位加权
        if lower in cls.CENTRAL_CORRECT_POSITIONS or upper in cls.CENTRAL_CORRECT_POSITIONS:
            base_score *= 1.5
        
        strengths[(lower, upper)] = base_score
    
    return strengths
```

## 四、约束和原则

### 4.1 不可违反的原则

🚫 **禁止事项**:
1. 添加 6-bit 状态码之外的并行控制变量
2. 引入置信度、优先级、重试分数等外部标志
3. 绕过 `IchingKernel.transition()` 的决策权威
4. 破坏 Lyapunov 非递增性质
5. 添加不安全的状态转换碰撞

✅ **必须遵守**:
1. 所有新规则闭合在现有 6-bit 表面
2. 外部事实只作证据，不作规则
3. 五行生克关系不可修改
4. 权威链完整性：yin/yang → 三卦 → 五行 → 平衡 → 转换 → 调度
5. 每个变更必须有失败测试驱动

### 4.2 质量门控

每个任务完成后必须通过：

```bash
# 1. 编译检查
python3 -m compileall src tests

# 2. 核心验证
bash scripts/verify-core.sh

# 3. 完整测试
PYTHONPATH=src python3 -m unittest discover -s tests -v

# 4. 数学审计
PYTHONPATH=src python3 -m onecode math-audit

# 5. 核心功能
PYTHONPATH=src python3 -m onecode doctor

# 6. 源码质量
git diff --check
```
