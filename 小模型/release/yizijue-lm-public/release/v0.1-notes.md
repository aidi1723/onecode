# YiZiJue-LM v0.1

YiZiJue-LM v0.1 is the first local release of the OneCode Agent intent proposal model.

## Positioning

YiZiJue-LM is built for OneCode Agent applications, not human-facing chat. It proposes controlled action JSON for OneCode to validate, authorize, execute, and audit.

The model is based on Qwen3-0.6B.

## Included Directory Contents

This public directory contains:

- final guarded evaluation reports;
- local MLX HTTP service;
- evaluation scripts;
- tests;
- documentation.

The final v5 LoRA adapter is distributed separately from this source directory and must be provided through `--adapter-path` or `YIZIJUE_ADAPTER_PATH` when starting the service.
